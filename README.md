# 🎮 Task 1: Hangman Game

## 📌 Description

The Hangman Game is a simple text-based game where the player guesses a hidden word one letter at a time.

The program randomly selects a word from a predefined list. The player is allowed a maximum of **6 incorrect guesses**.

## ✨ Features

* Random word selection
* One-letter-at-a-time guessing
* Maximum 6 incorrect guesses
* Input validation
* Displays guessed letters
* Win and lose conditions
* Console-based interface

## 🧠 Concepts Used

* Python `random` module
* Lists
* Strings
* Variables
* `while` loop
* `for` loop
* `if-else`
* User input

## ▶️ Run the Program

```bash
python hangman.py
```

## 📂 File

```text

```

# ⚙️ Task 3: Task Automation with Python

## 📌 Description

This project demonstrates how Python can be used to automate a repetitive task.

The selected automation task is **extracting email addresses from a text file and saving them into another file**.

The program reads the input text file, searches for email addresses using a regular expression, and saves the extracted email addresses into a separate file.

## ✨ Features

* Reads text from a file
* Finds email addresses automatically
* Uses regular expressions
* Saves extracted emails into another file
* Reduces repetitive manual work

## 🧠 Concepts Used

* `re` module
* File handling
* Regular expressions
* Lists
* Loops
* String processing

## ▶️ Run the Program

```bash
python email_extractor.py
```

## 📂 Files

```text
email_extractor.py
input.txt
emails.txt
```

# 🤖 Task 4: Basic Chatbot

## 📌 Description

The Basic Chatbot is a simple rule-based Python chatbot.

The chatbot accepts messages from the user and provides predefined responses.

For example, it can respond to messages such as:

```text
hello
how are you
bye
```

## ✨ Features

* Accepts user input
* Provides predefined responses
* Supports greetings
* Responds to basic questions
* Continues conversation using a loop
* Exits when the user enters `bye`

## 🧠 Concepts Used

* Functions
* `if-elif-else`
* `while` loop
* Strings
* User input
* Predefined responses

## ▶️ Run the Program

```bash
python chatbot.py
```

```text
chatbot.py
```
